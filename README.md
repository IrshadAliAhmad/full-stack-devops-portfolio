# Portfolio Backend API

A production-ready backend for my personal portfolio website built with Node.js, Express.js, PostgreSQL, and JWT Authentication.

## Features

* RESTful API Architecture
* PostgreSQL Database Integration
* JWT Authentication
* Protected Admin Routes
* Project CRUD Operations
* Contact Form API
* Email Notifications with Nodemailer
* Environment Variable Configuration
* CORS Enabled
* Error Handling
* Secure API Structure

---

## Tech Stack

* Node.js
* Express.js
* PostgreSQL
* JWT (JSON Web Token)
* bcryptjs
* Nodemailer
* dotenv
* cors


## Security

* JWT Authentication
* Protected Routes
* Password Hashing
* Environment Variables
* Input Validation
* Secure Database Queries
